Дни рождения для Homey

Управляйте днями рождения и получайте надёжные напоминания в Homey. Также можно использовать приложения, например WhatsApp for Homey, чтобы отправлять личные поздравления имениннику.

Возможности:
- Добавление, редактирование, поиск и фильтрация дней рождения по категориям.
- Использование данных, возраста, категории и изображений в токенах Flow.
- Запуск Flow для сегодняшних и предстоящих дней рождения.
- Подписка на онлайн-календари iCal, включая общие календари Google.
- Импорт локальных файлов календаря .ics.
- Используется часовой пояс, настроенный на Homey пользователя.

Использование:
Установите приложение, откройте настройки и добавьте дни рождения вручную либо импортируйте их через CSV, URL подписки iCal или файл .ics. Существующие списки и Flows продолжают поддерживаться.

Поддерживаемые языки:
Английский, нидерландский, немецкий, французский, итальянский, шведский, норвежский, испанский, датский, русский, польский, корейский и арабский.
